# Main menu / Options artwork (all optional)

Every file here is optional: the game draws built-in vector art when a PNG is missing. Drop transparent PNGs in
this folder with these exact names (square icons ~256x256, logo ~1024 wide):

| file | used for |
|------|----------|
| logo.png | bottom-centre title |
| play.png, profile.png, options.png | the three squares on the right |
| photo.png, news.png | small icons top-left / top-right |
| user.png | avatar in the top-right chip |
| opt_game.png, opt_display.png, opt_graphics.png, opt_audio.png, opt_controls.png | Options home cards |
